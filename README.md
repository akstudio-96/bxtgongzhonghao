# 🧲 冰箱贴大王 · 公众号自动化生产工具

**本地网页应用**：搜集热点 → 模仿您的风格生成冰箱贴公众号文章 → 配图+排版 → 存入微信草稿箱 → 推送审稿通知到您微信。您审稿 OK 就发布。

适配您的账号情况：**个人未认证订阅号**（draft/add 接口若有权限则自动用API；无权限则自动切降级模式，复制HTML到后台即可，不影响核心流程）。

## 一、回家后的 6 步快速启动

```bash
# 1. 克隆/进入项目
cd /path/to/this/project

# 2. 安装依赖（首次即可，后续不用）
npm install   # 需要 Node.js >= 18

# 3. 配置凭证 · 最关键的一步
cp .env.example .env
vim .env      # 或任何编辑器打开 .env，填下面4行
```

`.env` 里必须填的内容（剩下的看需要填）：

```env
# ① 微信公众号：在 mp.weixin.qq.com → 设置与开发 → 基本配置 里复制
WECHAT_APPID=wxf3dfd29c06f302ce
WECHAT_APPSECRET=您重置后的新AppSecret

# ② LLM（大模型）：建议 DeepSeek，便宜好用，兼容OpenAI格式
#    去 https://platform.deepseek.com 注册，拿 API Key 贴到下面
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
LLM_MODEL=deepseek-chat

# ③ Server酱（推送审稿通知到您的微信）
#    去 https://sct.ftqq.com 用微信扫码登录，拿 SendKey 贴到下面
SERVERCHAN_SENDKEY=SCT123456Txxxxxxxxxxxxxxxxxxxxxxxxxxx
```

```bash
# 4. 启动工具
npm start
# 看到 🟣 已启动 字样后，浏览器打开
# http://localhost:3000
```

**5. 初始化 Tab 里的操作**（只做一次，或者需要更新时做）：
   - 复制页面上显示的「本机出口IP」，粘贴到公众号后台「IP白名单」保存
   - 导入历史文章（详见下一节）
   - 点「开始学习风格」→ 生成风格画像 + 排版模板

**6. 日常使用**：热点搜集 Tab → 挑热点 "用这个写" → 生成 Tab → 推草稿箱 → 推送通知 → 您收到微信消息 → 审稿 → 手动发布。

## 二、初始化 · 历史文章导入方法

您的账号是个人未认证订阅号，无法通过 API 自动拉取，请**手动导入**。建议把已发的十多篇全部导入，学习效果最好。

每篇文章的导入步骤：
1. 登录 mp.weixin.qq.com → 「内容与互动」→「发表记录」
2. 打开一篇已发布文章 → 在新标签里显示完整文章
3. 在文章页面 → 右键「查看网页源代码」（或 Ctrl+U）
4. 全选所有 HTML（Ctrl+A → Ctrl+C）
5. 回到工具「初始化」Tab → 粘贴到「文章HTML原文」文本框
6. （可选）填好标题、作者
7. 点「导入这篇」

全部导入完后，点「开始学习风格」，大约10秒生成风格档案。档案生成后在页面下方能看到：语气调性、典型开头结尾、高频样式等，您可以肉眼判断是否贴合。

如果需要**重新学习**（比如又导入了几篇新文章），再次点「开始学习风格」即可覆盖旧档案。

## 三、日常生产流程（每日5步）

```
  ①热点搜集  →  ②生成文章  →  ③配图+渲染  →  ④推草稿箱  →  ⑤推送通知
```

| 步骤 | Tab | 操作 | 说明 |
|---|---|---|---|
| ① | 热点搜集 | 点"重新抓取热点" → 用筛选框找"强/中关联"的热点 → 点"用这个写" | 来源：微博、百度、微信热搜；自动按冰箱贴关联度打分排序 |
| ② | 生成/编辑 | 自动带着热点，点"✨生成文章" | 约20秒，LLM 按风格档案写 Markdown 中间稿 + 标题候选 + 配图建议 |
| ③ | 草稿详情页 → 配图+渲染 | 点"🎨配图+渲染微信HTML" | 自动搜 Unsplash/Pexels 真实图（没配 Key 就用占位图），套排版模板生成内联样式 HTML |
| ④ | 草稿详情页 → 推草稿箱 | 点"📮推入微信草稿箱" | 自动传封面、传正文图、调 draft/add 写草稿。**若API报48001则自动切降级模式**，给您一份渲染好的 HTML，复制粘贴到后台即可 |
| ⑤ | 草稿详情页 → 通知 | 点"🔔推送审稿通知" | Server酱把文章摘要 + 预览 + 下一步指引推送到您的个人微信，您收到后去公众号助手审稿发表 |

所有中间稿、草稿、通知记录都存在 `data/` 目录下，可随时回去重看/编辑/重跑。

## 四、关于 draft/add 权限（个人号常见问题）

个人未认证订阅号 `draft/add` 接口是否能调用，微信官方文档并不完全一致，不同号可能结果不同。我们设计了**双路径自动降级**：

| 情况 | 工具表现 |
|---|---|
| 接口有权限（成功返回 media_id）| ✅ 直接写进草稿箱，您在「公众号助手」/后台草稿箱能看到，手机点发表即可 |
| 接口返回 48001 / 48002（权限不足）| ⚠️ 自动切降级模式：把已排好版、已换好图床URL的HTML给您，一键复制，粘贴到公众号后台，图文样式基本保留，手动微调+传封面即可 |

所以即使 draft/add 对您的号不可用，整个生产流依然跑的通，只是"推草稿箱"这步变成了「复制 HTML → 粘贴」15秒的事。

## 六、安全与隐私

- **不要把 `.env` 提交到任何公开仓库**（已写进 `.gitignore`）。
- **AppSecret 在对话里出现过**，建议回家后立刻去公众平台后台「基本配置」点「重置」换一个新的，旧的立刻失效，再填到 `.env` 里。这是个好习惯，和您换银行卡密码同理。
- 所有文章、素材、风格档案全部落地在本地 `data/` 目录，不上传任何第三方服务器。
- LLM 请求只发"文章正文生成"与"风格学习"两类，不含您的微信密钥；图片请求只发描述词，不含您的账号信息。
